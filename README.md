# 🗂 Планировщик проектов

Веб-приложение для управления проектами: список текущих проектов, задачи с напоминаниями,
хранилище файлов внутри задач и встроенный анализатор проектов.

## Возможности
- **Проекты** — создание, описание, статусы (активен / пауза / завершён), удаление.
- **Задачи внутри проекта** — название, описание, приоритет (низкий/средний/высокий),
  дата и время напоминания, отметка «выполнено».
- **Напоминания** — фоновый поток каждые 30 секунд проверяет наступившие сроки;
  в интерфейсе просроченные задачи мигают бейджем «🔔 НАПОМИНАНИЕ».
- **Файлы в задачах** — к любому типу файлам (документы, картинки, архивы…): загрузка,
  скачивание, удаление. Хранятся в `app/data/uploads/`, метаданные — в SQLite.
- **Анализатор** (`/api/analyze` и вкладка «📊 Анализатор») — сводная статистика:
  число проектов/задач, просрочки, % завершения по каждому проекту, объём хранимых
  файлов и автоматические рекомендации (что разобрать первым, где нет сроков и т.п.).

## Структура
```
app/
  main.py          — Flask-приложение, REST API, фоновые напоминания
  database.py      — схема SQLite (projects, tasks, files)
  analyzer.py      — логика анализатора проектов
  templates/index.html — интерфейс (вкладки Проекты / Анализатор)
  static/app.js, style.css
  data/            — planner.db и uploads/ (создаются автоматически, в .gitignore)
```

## Запуск локально
```bash
pip install -r requirements.txt
python app/main.py        # откройте http://localhost:5000
```

## Запуск в Docker
Через docker-compose (рекомендуется — данные сохраняются в volume `planner-data`):
```bash
docker compose up -d --build     # собрать и запустить
docker compose logs -f           # посмотреть логи
docker compose down              # остановить (данные останутся в volume)
```

Или просто docker:
```bash
docker build -t planner .
docker run -d -p 5000:5000 -v planner-data:/app/app/data --name planner planner
```
Приложение будет доступно на http://localhost:5000.

## API
| Метод | Путь | Действие |
|---|---|---|
| GET/POST | `/api/projects` | список / создание проекта |
| PUT/DELETE | `/api/projects/<id>` | изменить / удалить проект |
| GET | `/api/projects/<id>/tasks` | задачи проекта (с файлами) |
| POST/PUT/DELETE | `/api/tasks...` | создать / изменить / удалить задачу |
| POST | `/api/tasks/<id>/files` | прикрепить файл к задаче |
| GET | `/files/<id>/download` | скачать файл |
| GET | `/api/analyze` | отчёт анализатора |
